# SafeLogins
API and Web app that stores passwords. 

# Features
- Adding/Editing Passwords 
    - check for password strength
    - add urls associated with password
 - Search for passwords
 - Add password keys
 - Update Profile
 - Share password with phone number
 - Block Tor Web Browsers
 - Extension Auto Log
 - MFA
